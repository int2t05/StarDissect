如何选择

  1. 先看 16px 列：哪个在"最小处"仍然像自己的产品——favicon 与浏览器标签是出现频率最高的位置。
  2. 再看叙事契合：A 讲"解剖"（过程），C 讲"收藏变学习"（价值链），B 讲"分析"（动作），D 讲"聚焦"（态度）。
  3. 把候选放到模板里看：打开 [style-a / style-b / style-c 模板](../mockups/style-a-editorial.html)，其导航品牌位可临时替换为候选 SVG 再决定。
  4. 选定后由实现落地为 favicon.ico + PWA 图标 + 浅色/深色变体，本页的深浅底对照即验收基准。
