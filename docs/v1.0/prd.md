## 2. 功能需求

规则:核心 REQ 均含 触发/行为/输出/异常;每条关联 ≥1 G 与 ≥1 AC。行为细节引用 UIUX 的不再重复。

### 2.1 同步

**REQ-SYNC-001 star 自动同步**(G-01 · AC-001/AC-003)
- 触发:每 8 小时定时到达,或手动触发;输入为 GitHub 账号的 star 列表。
- 行为:增量比对本地库——新增仓库入库并进入自动分类;取消 star 的仓库标记「已取消收藏」,不删除任何已有数据;fork 与 archive 仓库不入库。
- 输出:同步记录(新增/取消/跳过/失败计数)。
- 异常:凭据失效→同步失败并提示重新配置;接口限流→本轮记「跳过」,等待下轮,不影响已入库数据。

**REQ-SYNC-002 手动同步幂等**(G-01 · AC-002)
- 触发:设置页或仓库库的「立即同步」。
- 行为:同步进行中重复触发合并为一次,不产生并发同步。
- 异常:触发时上一轮仍标记失败未清理→正常发起新一轮,以新一轮结果为准。

**REQ-SYNC-003 同步结果可见**(G-01 · AC-001)
- 触发:每轮同步结束。
- 行为:在仓库库与设置页展示最近一次同步的时间与结果计数。
- 异常:同步从未执行→显示「从未同步」引导配置。

### 2.2 分类

**REQ-CLS-001 自动分类**(G-01/G-02 · AC-004)
- 触发:仓库入库后。
- 行为:判定为七类主类型之一(→项目 PRD FIG-03/主类型表),输出类型+判定理由+置信(高/中/低)+2–4 个主题标签(写入 auto_tags,独立于人工标签);置信为定性级别,不输出统计概率。
- 输出:仓库的分类记录(类型/理由/置信/时间)。
- 异常:分类失败→仓库停留「已收录」,可在仓库库重新触发。

**REQ-CLS-002 低置信与待处理**(G-01 · AC-005)
- 触发:分类结果为低置信,或分析中无法确定类型。
- 行为:低置信不是自动失败,仓库照常排队分析;只有无法形成可信分析范围(典型为混合/未识别)才进入「待处理」,等待人工选择范围。
- 异常:人工选择范围后回到「已分类」并入队。

**REQ-CLS-003 人工锁定**(G-02 · AC-006)
- 触发:用户在仓库页锁定当前分类。
- 行为:锁定后,任何自动流程(含深读修正)不得更改该分类;解锁后方可再被修正。
- 异常:深读遇到与锁定分类冲突的强证据→不改正文结论方向,在报告中以「未知/冲突」证据呈现。

**REQ-CLS-004 深读修正**(G-02 · AC-007)
- 触发:分析过程中获得比入库时更强的分类证据。
- 行为:修正分类并留变更记录(旧类型→新类型+理由),用户可见;已锁定的除外(→REQ-CLS-003)。
- 输出:仓库页展示当前分类与修正历史。

**REQ-CLS-005 人工标签**(G-02/G-03 · AC-008)
- 触发:用户在仓库页增删标签。
- 行为:人工标签立即影响仓库库的筛选与整理;与报告知识点分开显示;自动流程不得增删改人工标签;人工标签可随时编辑,不受报告版本影响。
- 异常:无。

### 2.3 任务与队列

**REQ-TASK-001 自动队列**(G-01/G-04 · AC-009)
- 触发:仓库完成分类(含低置信)后。
- 行为:自动入队;新 star 仓库排在历史批次之前;历史收藏全量入队按顺序推进;队列页展示 排队/进行/完成/失败 各任务状态。
- 异常:仓库被排除(→REQ-TASK-002)→不入队;已在队中不重复入队。

**REQ-TASK-002 队列干预**(G-04 · AC-010)
- 触发:用户操作。
- 行为:支持 1) 暂停/恢复整个队列;2) 调整单个任务优先级;3) 取消排队中任务;4) 排除某仓库——不自动分析,已有报告保留。
- 异常:「分析中」任务不可直接取消优先级调整;可终止(归入失败,可重试)。

**REQ-TASK-003 限额约束**(G-04 · AC-011、NFR-01)
- 触发:每个分析任务执行全程。
- 行为:任务受「最大轮次」与「总时限」双重约束(默认值见 OPN-02,可配置);达到任一上限即终止,任务归「失败」,可手动重试(DEC-09 轻量语义,不保留部分产出)。不得无限消耗。
- 输出:任务记录标注失败原因(轮次/时限)与失败时间。
- 异常:限额配置为 0 或非法→拒绝保存,沿用上一个合法值。

**REQ-TASK-004 失败与重试**(G-01 · AC-012)
- 触发:任务失败/中断,或用户主动重试。
- 行为:失败与中断任务可手动重试;每次执行产生新任务记录,不覆盖历史;同仓库同时只允许一个进行中任务;网络类失败(clone/模型网关)自动重排至多 3 次,无需人工盯守。
- 异常:重试时该仓库已有进行中任务→拒绝并提示。

**REQ-TASK-005 手动重新分析**(G-01/G-02 · AC-013)
- 触发:用户在仓库页点击「重新分析」。
- 行为:重新走完整分析流程,成功后生成新报告版本;旧版本全部保留可回看;不自动触发(→SCP-02)。
- 异常:进行中不可重复触发(→REQ-TASK-004 并发防护)。

**REQ-TASK-006 中断恢复**(G-04 · AC-014)
- 触发:服务重启或异常退出。
- 行为:排队任务完整保留;「分析中」任务标记「中断」等待人工重试,不自动续跑(快速原型简化)。
- 异常:重启时正在写入的产物→该任务按失败处理,产物不留半成品。

### 2.4 报告与证据

**REQ-RPT-001 报告结构**(G-01 · AC-015)
- 触发:分析任务执行。
- 行为:每仓库一份连贯报告=通用基础章节+主类型模块(→项目 PRD FIG-03/主类型表)+按需模块(证据充分才写);叙事守则=短段落(每段≤4 句)、图优先(每大章节至少一张 mermaid 图,全文≥3 张)、术语首次出现即一句话解释、语域介于大白话与术语之间;混合/未识别类型以「实际内容+不确定性说明」替代类型模块,必要时采用人工选择范围。
- 输出:含目录、章节、证据块、图表的报告正文。
- 异常:某章节证据不足→明确写「证据不足」,不虚构填充。

**REQ-RPT-002 证据五类**(G-02 · AC-016/AC-017)
- 触发:报告撰写全程。
- 行为:每条结论归属五类证据之一(→项目 PRD 证据五类表);源码事实必须含 路径:行号 并锚定生成时的代码快照,可跳转核对;分析推断不得表述为事实;矛盾证据以「未知/冲突」呈现,不强行消除。
- 异常:无法核实的引用一律降级为「未知/冲突」,不得保留事实外观。

**REQ-RPT-003 中文与排版校验**(G-01/G-02 · AC-018)
- 触发:报告发布前。
- 行为:正文为中文;按中文排版规则集(UIUX-16…20)校验,违规项在报告中标记展示;支持白名单例外(产品名官方拼写等);校验不通过不阻断发布(快速原型)。
- 异常:校验器自身故障→跳过校验并在报告元信息标注「未校验」。

**REQ-RPT-004 报告版本**(G-02 · AC-013)
- 触发:每次分析成功。
- 行为:生成新报告版本,记录 生成时间/代码快照锚点/当时的分类快照;版本列表可回看、可下载;阅读进度按版本存储(→REQ-READ-003);跨版本进度迁移不在本版(→SCP-03)。
- 异常:无(版本只增不覆)。

**REQ-RPT-005 图表**(G-01/G-03 · AC-025)
- 触发:报告含图。
- 行为:图渲染+图题+文字后备;宽表格容器内滚动不破版(→UX-48);导出保留图源码(→REQ-OUT-001)。
- 异常:渲染失败→展示文字后备,不空块。

### 2.5 知识点

**REQ-KP-001 知识点提取**(G-02/G-03 · AC-019)
- 触发:报告生成时。
- 行为:从报告中抽取证据支持的知识点为独立条目:结论+证据引用+来源报告版本+所属仓库;随报告版本保存,旧版本知识点随之保留。
- 输出:仓库页与报告页的知识点列表。
- 异常:某报告未产出知识点→允许为空,不凑数。

**REQ-KP-002 知识点编辑边界**(G-02 · AC-008/AC-020)
- 触发:用户编辑知识点(措辞修正/删除)。
- 行为:人工修订必须标注「人工修订」,不得冒充分析结论;人工编辑不影响人工标签,人工标签变动也不影响知识点;修订随版本留痕。
- 异常:删除知识点为软删除,可恢复,不破坏版本完整性。

### 2.6 阅读中心

**REQ-READ-001 阅读排版与格式调节**(G-03 · AC-021)
- 触发:打开报告。
- 行为:按 UIUX §3 排版规格渲染;行宽、字号、行高、主题、强对比的档位与范围按 UIUX 定稿(→UX-10、UX-30…34);偏好本地保存(→DEC-04)。
- 异常:偏好损坏→回退默认值。

**REQ-READ-002 目录与定位**(G-03 · AC-021)
- 触发:报告页滚动或点击目录。
- 行为:右侧目录随滚动高亮当前章节(→UX-59);点击目录平滑定位;平板折叠浮动按钮,移动端章节下拉(→UX-22…24)。
- 异常:章节锚点缺失→目录项禁用不报错。

**REQ-READ-003 阅读进度**(G-03 · AC-021)
- 触发:阅读中定期上报;换设备打开。
- 行为:按「锚点+视口百分比+高水位」存储并跨设备恢复;仅当新位置大于已存位置才更新(防回退);显式重置到开头用零值特判(→UX-26…28)。
- 异常:上报失败→本地缓存待重传,不丢进度。

**REQ-READ-004 键盘导航**(G-03 · AC-022)
- 触发:非输入焦点下的按键。
- 行为:miniflux 式处理器:`g u/b/h/s` 跳四区、`/` 搜索、`j/k` 条目间移动、`o/Enter` 打开、`m` 已读切换、`f` 收藏、`?` 帮助(→UX-35…37);输入框聚焦时全部忽略。
- 异常:未知组合→不响应不报错。

**REQ-READ-005 证据交互**(G-02 · AC-016)
- 触发:点击证据块。
- 行为:五类证据的视觉与形态按 UIUX §8;源码事实点击打开锚定代码快照的源文件;外部链接标注来源与查阅时间。
- 异常:快照文件已不可达→提示不可用,不降级为外链猜测。

**REQ-READ-006 已读与收藏**(G-03 · AC-022)
- 触发:阅读中心列表或阅读页操作(含键盘 m/f)。
- 行为:报告条目级已读切换与收藏;列表支持按未读/收藏/仓库筛选;状态即时生效。
- 异常:无。

### 2.7 检索

**REQ-SRCH-001 全文检索**(G-03 · AC-023/AC-024)
- 触发:搜索弹层输入(`/` 或点击唤起)。
- 行为:检索范围=报告全文+知识点+仓库元信息(名称/描述/人工+自动标签);结果按「报告>章节」两级分组,命中片段高亮;上限 16–20 条、输入 debounce 200ms;中文输入法组词中的回车不得触发跳转(→UX-39);键盘 ↑↓ 环绕选择。
- 异常:索引缺失(新报告未入索引)→结果为空,不报错;索引在报告发布后补建。

**REQ-SRCH-002 空态与记忆**(G-03 · AC-024)
- 触发:搜索无结果或反复搜索。
- 行为:空结果态延迟出现避免闪烁;查询在会话内保留;视图偏好本地保存(→UX-38/42)。
- 异常:无。

### 2.8 导出与订阅

**REQ-OUT-001 Markdown 导出**(G-03 · AC-025)
- 触发:报告页「导出」。
- 行为:导出单篇报告为 Markdown 文件:含全部证据块、图源码与元信息(仓库/版本/生成时间/代码快照锚点);文件可独立阅读。
- 异常:导出失败→提示并保留页面状态;批量导出不在本版(→SCP-03)。

**REQ-OUT-002 RSS 订阅**(G-03 · AC-026)
- 触发:新报告版本发布。
- 行为:全站单一订阅源;每个新报告版本产生一条目(标题+摘要+链接);供本人 RSS 阅读器追踪,仅内网使用。
- 异常:feed 为空→返回合法空 feed,不报错。

### 2.9 配置

**REQ-CFG-001 系统设置**(G-04 · AC-027)
- 触发:设置页操作。
- 行为:配置项=GitHub 连接(token 及校验)、AI 服务(供应商/模型/密钥)、任务限额(轮次/时限);密钥仅服务端存储,界面永不回显明文(仅显示尾号)。
- 异常:GitHub 连接校验失败→标红提示,不阻塞其他设置项保存。

**REQ-CFG-002 配置生效规则**(G-04 · AC-028)
- 触发:限额类配置修改。
- 行为:新限额对修改之后启动的任务生效;进行中任务按启动时的限额继续,不被中断。
- 异常:非法值→拒绝保存(→REQ-TASK-003)。

## 4. 验收标准

| ID     | 前置                     | 操作                             | 可观察结果                                                       | 关联           |
| ------ | ------------------------ | -------------------------------- | ---------------------------------------------------------------- | -------------- |
| AC-001 | 已配置 GitHub 连接       | 手动同步一轮                     | 产生同步记录:新增/取消/跳过/失败计数正确;设置页与仓库库可见时间  | SYNC-001/003   |
| AC-002 | 同步进行中               | 再次点击「立即同步」             | 不产生第二个并发同步;最终只有一轮结果                            | SYNC-002       |
| AC-003 | 账号含 fork 与 archive star | 同步                           | 两类仓库均不入库                                                 | SYNC-001       |
| AC-004 | 新仓库入库               | 查看分类结果                     | 有类型+理由+高/中/低置信,无百分比概率                            | CLS-001        |
